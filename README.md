# KingIn Trading System

A professional institutional-grade trading dashboard and engine for MetaTrader 5.

## 📂 Structure
- **`backend/`**: Trading Engine (Python/FastAPI)
- **`frontend/`**: Dashboard UI (React/Electron)

## 🚀 Getting Started
For new machine setup and installation, please refer to the detailed [INSTALLATION_GUIDE.md](./INSTALLATION_GUIDE.md).

## ⚡ Quick Launch
- **Development:** Run `START_SYSTEM.bat`
- **Build Release:** Run `BUILD_APP.bat`
- **Portable App:** Located in `frontend/dist_electron/`
