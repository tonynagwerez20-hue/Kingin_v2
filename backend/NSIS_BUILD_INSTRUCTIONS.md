# Building the Windows NSIS Installer (local)

This document explains how to compile the NSIS installer generated by the Tauri build on your Windows machine.

Prerequisites

- Windows machine with Administrator access for creating per-machine shortcuts.
- NSIS (makensis) installed and available in PATH or at `C:\Program Files\NSIS\makensis.exe`.
  - Download: https://nsis.sourceforge.io/Download
- (Optional) If you want `npm run tauri:build` to produce the installer automatically, install NSIS before running it.

Files of interest

- Generated NSIS script: `src-tauri\target\release\nsis\x64\installer.nsi`
- Helper script (this repo): `scripts\compile_nsis_installer.bat`
- Expected installer output (default in script): `nsis-output.exe` (in the same folder as `installer.nsi`)

Quick steps (recommended)

1. Build frontend and Tauri bundle (already done if you ran `BUILD_DESKTOP_APP.bat`):

```powershell
# from repo root
npm ci
npm run build
# if you have makensis installed you can run:
npm run tauri:build
# otherwise use the helper below to compile existing NSIS script
```

2. Compile the NSIS script directly (if `tauri:build` did not produce the installer or you prefer manual compile):

```powershell
# Open PowerShell as Administrator (required to create per-machine shortcuts)
cd src-tauri\target\release\nsis\x64
# If NSIS is on PATH:
makensis installer.nsi
# Or use full path to makensis:
"C:\Program Files\NSIS\makensis.exe" installer.nsi
```

- The compiled installer filename is set in the NSIS script (`OutFile "nsis-output.exe"`). You can change that name in the script or pass defines to `makensis`.

3. Run the installer with elevation to create Public (All Users) shortcuts:

```powershell
Start-Process -FilePath .\nsis-output.exe -Verb runAs
```

Notes & troubleshooting

- If makensis reports missing NSIS plugins, check the `!define ADDITIONALPLUGINSPATH` in the top of `installer.nsi` and either copy plugin files there or remove/adjust that include.
- If you prefer the Tauri CLI to run the full flow automatically, install NSIS and then run:

```powershell
npm run tauri:build
```

- The helper script `scripts\compile_nsis_installer.bat` included in this repo will try to locate `makensis` and run it for you (see below).

Security and elevation

- A per-machine installer will request elevation (admin) during install and create shortcuts in the Public desktop. If you want per-user only, run the installer without elevation or modify the `installer.nsi` `INSTALLMODE` back to `currentUser`.
